# Memory पूरी करें

जब यात्रा या कार्यक्रम खत्म हो, **Memory पूरी करें** ताकि नए खर्च उसका उपयोग न करें। पूरा करने पर वह deactivated होती है। वह संग्रहित नहीं होती, और पहले से सहेजे लिंक नहीं हटते।

## पहले से चाहिए

- सक्रिय Split Smarter खाता
- ऐसी Memory जिसे आप बदल सकें (आमतौर पर जो आपने बनाई, या जिसे समूह बदल सके)

## पूरा करने से क्या होता है

1. **अंत** तय या पुष्टि होता है। वह तारीख आपकी समय-क्षेत्र में आज या बाद की होनी चाहिए, और शुरू के बाद।
2. Memory **deactivated** होती है। बंद करना या संग्रहित करना भी यही करता है। वह नए खर्चों पर नहीं आती।
3. पहले से सहेजे लिंक रह जाते हैं। शुरू और अंत छोड़ने की वजह से वे नहीं हटते, और नए नहीं जुड़ते।

खर्च Smart Ledger में रहते हैं। सिर्फ़ Memory मिटाने पर उसके लिंक हटते हैं।

## कदम

1. जो Memory खत्म करनी है, उसे खोलें।
2. **Complete** चुनें (या ऐप में समान क्रिया)।
3. अगर पूछा जाए तो अंत की तारीख पुष्टि करें। वह आपकी समय-क्षेत्र में आज से पहले का दिन नहीं हो सकती।
4. सहेजें या पूरा होने की पुष्टि करें।
5. जाँचें कि:
   - Memory deactivated दिखे।
   - नया खर्च उसका उपयोग न करे।
   - जो खर्च पहले से जुड़े हैं, वे अब भी उसे दिखाएँ।

## सुझाव

- सिर्फ़ बंद करने से भी नए खर्च उसका उपयोग नहीं करते, बिना समाप्त अंत रखे। अनुभव खत्म हो तो पूरा करें।
- अगले अनुभव के लिए दूसरी Memory बनाएँ या चालू करें।
