# खर्च पर Memory जोड़ें

खर्च को **Memory** से जोड़ना उस खर्च को एक अनुभव से बाँधता है (जैसे यात्रा)। आप क्या चुन सकते हैं, यह इस पर निर्भर है कि खर्च का दिन आपकी समय-क्षेत्र में आज है या नहीं।

## पहले से चाहिए

- सक्रिय Split Smarter खाता
- खर्च जोड़ने या बदलने की अनुमति
- आज के बिल के लिए, जो Personal Memories चाहिए वे पहले से चालू हों

## आज और पिछला दिन

**आज** आपकी समय-क्षेत्र का कैलेंडर दिन है। अगर समय-क्षेत्र नहीं है, तो आज UTC का दिन है।

आज के बिल पर:

- चुनें कि आपकी कौन सी चालू Personal Memories रहें। आप बिना किसी के भी सहेज सकते हैं।
- जो Group और Shared Memories चालू हैं, वे लग जाती हैं। किसी को छोड़ना हो तो सहेजने से पहले उसे बंद करें। आप उसे सिर्फ़ इस खर्च पर से नहीं हटा सकते।

पिछले दिन के बिल पर वह पसंद अनदेखी होती है। उस समय चालू हर Personal, Shared, और Group Memory जुड़ जाती है।

## कदम

### आज का खर्च जोड़ते समय

1. नया खर्च शुरू करें और समूह चुनें, अगर यह खर्च किसी समूह का है।
2. खर्च की तारीख आज रखें।
3. वे Personal Memories चुनें जो रहनी चाहिए। अगर कोई ठीक नहीं, तो सभी छोड़ दें।
4. चालू Group और Shared Memories लग जाएँगी। अगर यह बिल किसी का नहीं है, तो पहले उसे बंद करें।
5. किसने चुकाया, हिस्से, और राशि पूरी करके सहेजें।

### पिछले दिन का खर्च जोड़ते समय

1. खर्च की तारीख उस पिछले दिन पर रखें।
2. सहेजें। फ़ॉर्म पर चुनी Memories उपयोग नहीं होतीं। Split Smarter उस समय चालू हर Memory जोड़ता है।

### खर्च बदलते समय

1. खर्च खोलें।
2. अगर दिन पिछले पर रहता है, तो Memory लिंक वैसे ही छोड़ें। सहेजने से वे जुड़ते या हटते नहीं।
3. अगर दिन को आज पर ले जाएँ, तो Personal Memories फिर चुनें। Group और Shared वाले अब जो चालू हैं, उनसे लिए जाते हैं।
4. सहेजें।

## लिंक कौन देखता है

- **Group** Memory साझा खर्च पर है। समूह उसे देखता है।
- **Personal** Memory आपके दृश्य पर है। दूसरे लोग वह लिंक नहीं देखते।
- **Shared** Memory आपके और हर उस व्यक्ति के लिए रहती है जिसके साथ वह साझा है।

उसी खर्च पर **Place** या रसीद भी जोड़ सकते हैं। वह Memory लिंक से अलग है। देखें [जगह या रसीद जोड़ें](/hi/expenses/howto-attach-place-or-receipt)।
