# Memories

**Memory** एक अनुभव है—जैसे यात्रा, कार्यक्रम, या किसी काम का हफ़्ता—जिसे आप वहाँ जोड़ सकते हैं जहाँ खर्च होता है। इसमें Smart Ledger के खर्च और बजट का **क्या गिना जाएगा** शामिल है। Memory कोई Place नहीं है और अपने आप में कोई समूह नहीं है।

खर्च किसी Memory से तब जुड़ता है जब वह Memory चालू हो, इसलिए नहीं कि खर्च की तारीख आपके लिखे शुरू और अंत के बीच है।
