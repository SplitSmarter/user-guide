# Memory क्या है

**Memory** एक अनुभव के खर्च और फ़ोटो इकट्ठा करती है। वही Memory समूह से, खर्च से, और बजट से इस्तेमाल होती है। यह किसी एक स्क्रीन से बँधी नहीं है।

“यात्रा की Memory” सिर्फ़ एक आम उदाहरण है। हर Memory के हिस्से एक जैसे हैं।

खर्च किसी Memory से तब जुड़ता है जब उस खर्च के समय वह Memory चालू थी। जो शुरू और अंत आप लिखते हैं, वे अनुभव को बताते हैं। वे अपने आप यह नहीं तय करते कि कौन से बिल जुड़ेंगे।

## Memory कहाँ लगती है

- **समूह** — एक समूह के लिए एक Group Memory चालू हो सकती है। जब तक वह चालू है, उस समूह के खर्चों पर लगती है।
- **खर्च** — आज की तारीख वाले बिल पर आप चुन सकते हैं कि कौन सी चालू Personal Memories रहें। जो Group और Shared Memories चालू हैं, वे लग जाती हैं। अगर वह बिल किसी Group या Shared Memory का नहीं है, तो सहेजने से पहले उसे बंद कर दें।
- **कुछ दिनों की अवधि** — उन दिनों की सूची आपकी समय-क्षेत्र में वे Memories दिखाती है जो तब चालू थीं। समूहों से छानने पर सिर्फ़ उन समूहों की Memories दिखती हैं।
- **बजट** — बजट बनाते समय **क्या गिना जाएगा** में यह Memory चुनें। सिर्फ़ उससे जुड़ा खर्च उस सीमा में गिना जाता है। देखें [बजट बनाएँ](/hi/budgets/howto-create-a-budget)।
- **फ़ोटो** — तस्वीरें Memory पर रहती हैं, खर्च की रसीद से अलग।

**Place** एक सहेजा स्थान है। एक खर्च पर दोनों हो सकते हैं। वे अलग रहते हैं।
