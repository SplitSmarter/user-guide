# खर्च के लिंक

Memory तब उपयोगी होती है जब कोई **खर्च** उसकी ओर इशारा करे। कौन सी Memories जुड़ेंगी, यह इस पर निर्भर है कि खर्च का दिन आपकी समय-क्षेत्र में आज है या नहीं।

**आज**

- आप चुनते हैं कि आपकी कौन सी चालू [Personal Memories](/hi/memories/components/concept-scope) रहें। आप बिना किसी के भी सहेज सकते हैं।
- जो Group और Shared Memories चालू हैं, वे लग जाती हैं। किसी को छोड़ना हो तो सहेजने से पहले उसे बंद करें।

**पिछला दिन**

आपकी पसंद अनदेखी होती है। उस समय चालू हर Personal, Shared, और Group Memory जुड़ जाती है।

**संपादन**

जो खर्च पिछले दिन पर रहता है, उसके Memory लिंक वैसे ही रहते हैं। दिन को आज पर ले जाने से आप Personal वाले बदल सकते हैं। Group और Shared वाले अब जो चालू हैं, उनसे लिए जाते हैं।

- **Group** Memory साझा खर्च के साथ रहती है। समूह उसे देखता है।
- **Personal** Memory आपके दृश्य पर रहती है। दूसरे लोग वह लिंक नहीं देखते।
- **Shared** Memory आपके और हर उस व्यक्ति के लिए रहती है जिसके साथ वह साझा है।

जो शुरू और अंत आपने लिखे, वे लिंक को नहीं रखते और नहीं हटाते। Memory बंद करने या पूरा करने पर पहले से सहेजे लिंक रह जाते हैं। Memory मिटाने पर वे हट जाते हैं।

अगर आप पिछली शुरू वाली Memory बनाते हैं, तो उस अवधि का पहले से सहेजा खर्च बाद में जुड़ता है। वह काम सिर्फ़ लिंक जोड़ता है।

खर्च पर Place और रसीद भी हो सकते हैं। वे Memory लिंक से अलग हैं। कदम: [खर्च पर Memory जोड़ें](/hi/memories/guides/howto-attach-memory-to-expense)।
