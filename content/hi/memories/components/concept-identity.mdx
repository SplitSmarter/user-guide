# पहचान और आइकन

हर Memory का एक **शीर्षक** होता है, ताकि यात्राएँ और कार्यक्रम अलग दिखें। छोटा **विवरण** वैकल्पिक है। Group या Shared Memory में दूसरे लोगों को इससे समझ आता है कि यह किस बारे में है।

**आइकन** वैकल्पिक है। यह सूचियों में Memory का छोटा चित्र है। यह उन फ़ोटो से अलग है जो आप अनुभव पर जोड़ते हैं। वे Memory की गैलरी में रहती हैं। देखें [फ़ोटो](/hi/memories/components/concept-photos)।

ऐसा शीर्षक चुनें जो तारीख बदलने के बाद भी समझ आए, जैसे जगह या कार्यक्रम का नाम, सिर्फ़ “इस सप्ताहांत” नहीं।
