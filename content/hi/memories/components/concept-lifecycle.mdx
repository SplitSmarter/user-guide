# अवस्था

| अवस्था | अर्थ |
|--------|---------|
| **Active** | Memory चालू की जा सकती है। जब तक चालू है, नए खर्च उसका उपयोग कर सकते हैं। |
| **Deactivated** | आपने उसे बंद किया, पूरा किया, या संग्रहित किया। वह नए खर्चों पर नहीं आती। पहले से सहेजे लिंक रह जाते हैं। |
| **Deleted** | Memory सामान्य उपयोग से हट जाती है। खर्चों पर उसके लिंक भी हट जाते हैं। |

अधिकतर Memories आप बनाते हैं। Split Smarter कभी-कभी एक सिस्टम Memory जोड़ सकता है; जब तक ऐप उसे न दिखाए, उन्हें छोड़ दें।

पूरा करने से खर्च नहीं मिटते, और शुरू-अंत छोड़ने की वजह से लिंक नहीं हटते। देखें [Memory पूरी करें](/hi/memories/guides/howto-complete-a-memory)।
