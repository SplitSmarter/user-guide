# दायरा

**दायरा** तय करता है कि Memory किसके लिए है और खर्च पर इसे कौन देखता है। यह फ़ोटो नहीं बदलता, और यह सदस्यता की सेटिंग के रूप में सहेजा नहीं जाता।

| दायरा | किसके लिए |
|-------|----------------|
| **Personal** | सिर्फ़ आपके लिए। कई एक साथ चालू हो सकती हैं। बिल समूह में हो या नहीं, वे आपके खर्चों पर लगती हैं। आज की तारीख वाले बिल पर आप चुनते हैं कि चालू में से कौन सी रहें। |
| **Group** | जिस समूह से आप इसे जोड़ते हैं। उस समूह के लिए एक Group Memory चालू होती है। जब तक चालू है, समूह के खर्चों पर लगती है। लिंक साझा खर्च पर होता है। |
| **Shared** | आप और जिन्हें आप बुलाते हैं। यह Personal Memory नहीं है, और किसी समूह से बँधी नहीं है। जब तक चालू है, यह आपके और बुलाए लोगों के लिए लगती है। |

Group Memory को समूह चाहिए। Shared Memory उन लोगों का उपयोग करती है जिन्हें आप बुलाते हैं, और एक समूह से नहीं बँध सकती। Personal Memory आपकी रहती है।

दायरा इस बात से अलग है कि Memory [चालू](/hi/memories/components/concept-current-context) है या नहीं। एक Group Memory समूह की हो सकती है, और उसी समय आपकी Personal Memories भी चालू हो सकती हैं। आज की तारीख वाले बिल पर जो Group और Shared Memories चालू हैं, वे लग जाती हैं। अगर वह बिल किसी एक का नहीं है, तो सहेजने से पहले उसे बंद कर दें।
