# फ़ोटो

Memory बनाते समय या बाद में आप उस पर **फ़ोटो** जोड़ सकते हैं। वे अनुभव की हैं: यात्रा, कार्यक्रम, लोग। Memory पूरी करने के बाद भी वे उसी पर रहती हैं।

ये फ़ोटो खर्च की रसीदें नहीं हैं। रसीद की तस्वीर खर्च पर रहती है। Memory का आइकन भी अलग है: वह सिर्फ़ सूचियों का छोटा चिह्न है। देखें [पहचान और आइकन](/hi/memories/components/concept-identity)।

फ़ोटो Memory से जोड़ें। Memory से फ़ोटो हटाने पर उससे जुड़े खर्च नहीं मिटते।
