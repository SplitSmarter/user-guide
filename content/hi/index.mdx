# Split Smarter सहायता

Split Smarter दूसरे लोगों के साथ खर्च के लिए है।

**Smart Ledger** खर्च दर्ज करता है: किसने भुगतान किया, और कौन लागत बाँटता है। ये अलग बातें हैं। जिसने भुगतान किया, वही अपने आप अकेला देनदार नहीं होता।

**Debt Sync** बताता है कि कौन किसका देनदार है। यह दर्ज करना कि पैसा हिला, अपने आप बिल को कवर नहीं करता। उस भुगतान को खर्च पर निपटाएँ, ताकि बकाया राशि कवर हो।
