# जगह या रसीद जोड़ें

खर्च पर ये तीन अलग चीज़ें हैं।

- **जगह** खर्च की **Location** है: आपकी वर्तमान जगह, एक सहेजी जगह, या कोई नहीं। देखें [खर्च पर](/hi/places/concept-place-on-expense)।
- **रसीद** बिल की फ़ोटो है। यह जगह नहीं है।
- **व्यापारी की शाखा** वह जगह है जिसे आप ट्रांसफ़र पर व्यापारी चुनने के बाद चुनते हैं। देखें [ट्रांसफ़र पर](/hi/places/concept-place-on-transfer)।

जिस जगह को फिर इस्तेमाल करना है, उसे [जगह सहेजें](/hi/places/howto-save-a-place) में रखें। Memory अलग है: [खर्च पर Memory जोड़ें](/hi/memories/guides/howto-attach-memory-to-expense)।
