# जगहें

**जगह** एक स्थान है जिसे आप सहेजते हैं और फिर इस्तेमाल करते हैं। आप इसे मानचित्र पर खोज सकते हैं, या खुद पिन कर सकते हैं। यह Memory नहीं है। Memory खर्च को एक समय के आसपास इकट्ठा करती है। देखें [Memory क्या है](/hi/memories/concept-what-is-a-memory)।

जगह दो अलग जगहों पर दिखती है:

- खर्च पर यह उस खर्च की **Location** है। देखें [खर्च पर](/hi/places/concept-place-on-expense)।
- ट्रांसफ़र पर यह व्यापारी की **शाखा** है, वह जगह जहाँ पैसा गया। देखें [ट्रांसफ़र पर](/hi/places/concept-place-on-transfer)।

पहले एक सहेजें: [जगह सहेजें](/hi/places/howto-save-a-place)।
