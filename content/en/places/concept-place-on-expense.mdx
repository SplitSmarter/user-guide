# On an expense

When you add an expense, **Location** sits next to the category and the group.

- **Current location** uses where you are.
- A saved place uses a location you already kept. See [Save a place](/en/places/howto-save-a-place).
- **Add Loc** means this expense has no place. That is fine.

Opening the expense can show that place on the map.

This location is not a Memory. A Memory is the experience the spend belongs to. A receipt is a photo of the bill, not the place. The branch of a merchant belongs on a transfer, not on this chip. See [On a transfer](/en/places/concept-place-on-transfer).
