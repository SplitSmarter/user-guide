# Save a place

A saved place has a name and a location. You can open it again later, and you can mark it a favourite.

## Prerequisites

- An account you are signed in to

## Steps

1. Open the place picker, or open the map.
2. Search for the place, or use **Current location**. You can also pin a spot yourself.
3. Save it. Give it a name you will recognize.
4. Mark it a favourite if you use it often.

The same saved place can be the location on an expense or a merchant’s branch on a transfer.
