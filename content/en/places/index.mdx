# Places

A **place** is a location you save and use again. You can find it on the map or pin it yourself. It is not a Memory. A Memory groups spending around a time. See [What is a Memory](/en/memories/concept-what-is-a-memory).

A place shows up in two different spots:

- On an expense, it is the **Location** of that spend. See [On an expense](/en/places/concept-place-on-expense).
- On a transfer, it is the **branch** of a merchant, the place the money went. See [On a transfer](/en/places/concept-place-on-transfer).

Save one first: [Save a place](/en/places/howto-save-a-place).
