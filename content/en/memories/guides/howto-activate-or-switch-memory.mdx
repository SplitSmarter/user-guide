# Activate or switch memory

**Activation** turns a Memory on. While it is on, expenses at that time can belong to it. Turning it off does not finish it and does not change expenses you already saved.

## Prerequisites

- An active Split Smarter account
- At least one Memory you can use (usually with status Active)
- Membership in the group, when the Memory is a Group Memory

## What gets applied

| What you turn on | What happens |
|------------------|--------------|
| **Group Memory** | One is on for the group. Turning another on turns the previous one off. It is applied to expenses in that group. The link is on the shared expense. |
| **Personal Memory** | Several can be on at once. They are yours, not stored on a group. On a bill dated today, you choose which of them stay. |
| **Shared Memory** | Applied for you and for the people you invited while it is on. It is not a Personal Memory, and you do not pick it on the expense the way you pick a Personal one. |

## Steps

### Turn on a Group Memory

1. Open the group, or open the Memory and choose the group.
2. Activate the Group Memory you want.
3. Confirm it replaces the Group Memory that was on before.
4. On a bill dated today in that group, this Memory is applied. Turn the Memory off before you save if this spend should not use it.

### Turn on a Personal Memory

1. Open your Memories.
2. Choose a **Personal** Memory, or create one. It is not tied to a group.
3. Activate it. Other Personal Memories that are already on stay on.
4. On a bill dated today, choose which of your Personal Memories that are on should stay. You can leave all of them off.

### Turn on a Shared Memory

1. Open the Shared Memory, or create one and invite people.
2. Activate it.
3. While it is on, it is applied for you and for the people you invited. Turn it off before you save a bill dated today if that bill should not use it.

### Turn an active Memory off

1. Open the Memory.
2. Deactivate it. This does not complete or delete the Memory, and it does not remove links already saved.
3. Add an expense dated today and confirm it is no longer applied.

## Tips

- A start in the future is rejected. A start in the past turns the Memory on from that time.
- To finish a Memory so it is no longer offered, [complete it](/en/memories/guides/howto-complete-a-memory). That also deactivates it.
