# Activate or switch memory

**Activation** turns a Memory on so Split Smart selects it when you add an expense. You can turn it off on that expense before you save. Switching which Memory is on does not change expenses you already saved.

## Prerequisites

- An active Split Smart account
- At least one Memory you can use (usually with status Active)
- Membership in the group, when the Memory is for that group

## What gets selected

| What you turn on | What happens on the next expense |
|------------------|----------------------------------|
| **Group Memory** | Selected for everyone adding an expense in that group. Creating a Group Memory for a group turns it on and replaces the previous one. The link is on the shared expense. |
| **Personal Memory for a group** | Selected only on expenses you add in that group. The link stays on your view. Other members do not get it. |
| **Shared Memory** | Not selected for you. A Shared Memory does not belong to a group. Choose it yourself on the expense. |

## Steps

### Turn on a Group Memory

1. Open the group, or open the Memory and choose the group.
2. Activate the Group Memory you want.
3. Confirm it replaces the Group Memory that was on before.
4. Add an expense in that group and check that this Memory is selected. Turn it off on that expense if this spend should not use it.

### Turn on a Personal Memory for a group

1. Open the group.
2. Choose a **Personal** Memory (or create one for that group).
3. Activate it for that group.
4. Add an expense in that group. Your Personal Memory is selected along with the group's active Memory, if the group has one. Turn either off before you save.

### Turn an active Memory off

1. Open the Memory or the group's Memories.
2. Deactivate it. This does not archive or delete the Memory.
3. Add an expense in that group and confirm it is no longer selected.

## Tips

- Turn on a Memory whose dates still cover the days you will log. An expense will not save while a selected Memory's dates do not cover the expense date.
- To finish a Memory so it is no longer offered, [complete it](/en/memories/guides/howto-complete-a-memory) instead of only deactivating it.
