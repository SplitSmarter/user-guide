# Create a trip memory

Use this flow when you and a group travel together. You create one **Group Memory** for the trip dates. Split Smart then selects it on expenses in that group. Turn it off on any expense that is not part of the trip. Complete the Memory when the trip ends.

## Prerequisites

- An active Split Smart account
- A group for the trip (or create one first)
- Rough start and end dates for the trip

## Steps

### 1. Create the Memory

1. Open Memories for your account or from the trip group.
2. Create a new Memory.
3. Set a clear title (for example, the destination or trip name).
4. Choose **Group** scope and select the trip group.
5. Set the **start** and **end** dates so they cover every day you expect to spend on the trip.
6. Save. Creating a Group Memory for a group turns it on and replaces the Group Memory that was on before.

### 2. Add photos (optional)

1. Open the Memory you just created.
2. Attach photos or other images that belong to the trip (cover moments, not every receipt—receipts go on expenses).

### 3. Confirm it is on for the group

1. If the Memory is not already on for the group, activate it.
2. Add a trip expense and confirm this Memory is selected. Turn it off before saving if that expense is not part of the trip.

Details: [Activate or switch memory](/en/memories/guides/howto-activate-or-switch-memory).

### 4. Log expenses on the trip

1. Add expenses as usual in Smart Ledger, with this group selected.
2. Use expense dates that fall inside the Memory's date window. The expense will not save while a selected Memory's dates do not cover that date.
3. Leave this Memory selected on trip expenses. Turn it off on spending that should not count.

Details: [Attach memory to an expense](/en/memories/guides/howto-attach-memory-to-expense) and [Log your first expense](/en/getting-started/tut-log-first-expense).

### 5. Complete the Memory when you return

1. Open the Memory and choose complete (or equivalent).
2. Confirm the end date (often today) and that the Memory becomes archived.
3. Check that new expenses in the group no longer select it.

Details: [Complete a memory](/en/memories/guides/howto-complete-a-memory).

## What good looks like

- Trip expenses you saved with this Memory still show it when their dates fall in the window.
- After completion, the Memory is archived and is not selected on new expenses.
- Photos on the Memory still describe the trip. Settlement and balances stay on the expenses themselves.
