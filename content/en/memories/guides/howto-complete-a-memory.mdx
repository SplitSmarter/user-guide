# Complete a memory

When a trip or event is over, **complete** the Memory so it is no longer used on new expenses. Completing deactivates it. It does not archive it, and it does not remove links already saved.

## Prerequisites

- An active Split Smarter account
- A Memory you can edit (typically one you created or one the group can edit)

## What completion does

1. Sets or confirms an **end date**. That date must be today or a later day in your timezone, and after the start.
2. **Deactivates** the Memory. Turning it off or archiving it does the same. It is no longer offered on new expenses.
3. Leaves links already saved. It does not drop them because a date left the start and end, and it does not add new ones.

Expenses themselves stay in Smart Ledger. Only deleting the Memory removes its links.

## Steps

1. Open the Memory you want to finish.
2. Choose **Complete** (or the equivalent action in the app).
3. Confirm the end date if prompted. It cannot be a day before today in your timezone.
4. Save or confirm completion.
5. Check that:
   - The Memory shows as deactivated.
   - A new expense does not use it.
   - Expenses already linked to it still show it.

## Tips

- Deactivate alone also stops new expenses from using it, without setting a finished end. Complete when the experience is over.
- For the next experience, create or turn on a different Memory.
