# Complete a memory

When a trip or event is over, **complete** the Memory so it is no longer selected on new expenses and is marked finished (usually **Archived**).

## Prerequisites

- An active Split Smart account
- A Memory you can edit (typically one you created or one the group can edit)

## What completion does

1. Sets or confirms an **end date** (often today, if you do not pick another).
2. Moves the Memory out of everyday use (typically to **Archived**).
3. **Turns it off** so new expenses no longer select it. That applies whether it was the group's active Memory or your Personal Memory for a group.
4. **Drops expense links** that no longer fit the final date window. It does not add new links.

Expenses themselves stay in Smart Ledger. A Memory link drops only when the dates no longer match.

## Steps

1. Open the Memory you want to finish.
2. Choose **Complete** (or the equivalent action in the app).
3. Confirm the end date if prompted.
4. Save or confirm completion.
5. Check that:
   - The Memory shows as archived (or otherwise completed).
   - A new expense in that group does not select it.
   - Expenses that still fall inside the final window keep the Memory.

## Tips

- Complete after the last expense date you care about, or set the end date before completing.
- For the next experience, create or turn on a different Memory.
