# Attach memory to an expense

Linking a **Memory** to an expense ties that spend to an experience (for example a trip). What you can choose depends on whether the expense day is today in your timezone.

## Prerequisites

- An active Split Smarter account
- Permission to add or edit the expense
- For a bill dated today, the Personal Memories you want must already be turned on

## Today and a past day

**Today** is your timezone’s calendar day. If you have no timezone, today is a UTC day.

On a bill dated today:

- Choose which of your Personal Memories that are on should stay. You can save with none.
- Group and Shared Memories that are on are applied. To leave one off, turn it off before you save. You cannot clear it only on this expense.

On a bill dated on a past day, that choice is ignored. Every Personal, Shared, and Group Memory that was on at that time is attached.

## Steps

### When adding an expense dated today

1. Start a new expense and choose the group, if this spend belongs to one.
2. Set the expense date to today.
3. Choose the Personal Memories that should stay. Leave them all off if none of them fit.
4. Group and Shared Memories that are on will be applied. Turn one off first if this bill should not use it.
5. Finish paid-by, sharers, and amount, then save.

### When adding an expense on a past day

1. Set the expense date to that past day.
2. Save. Memories you pick on the form are not used. Split Smarter attaches every Memory that was on at that time.

### When editing an expense

1. Open the expense.
2. If its day stays in the past, leave the Memory links as they are. Saving does not add or remove them.
3. If you move the day onto today, choose the Personal Memories again. Group and Shared ones are taken from what is on now.
4. Save.

## Who sees the link

- A **Group** Memory is on the shared expense. The group sees it.
- A **Personal** Memory is on your view. Other people do not see that link.
- A **Shared** Memory is kept for you and for each person it is shared with.

You can still attach a **Place** or receipt on the same expense. That is separate from Memory links. See [Attach a place or receipt](/en/expenses/howto-attach-place-or-receipt).
