# Expense links

A Memory becomes useful when an **expense** points at it. Which Memories are attached depends on whether the expense day is today in your timezone.

**Today**

- You choose which of your [Personal Memories](/en/memories/components/concept-scope) that are on should stay. You can save with none.
- Group and Shared Memories that are on are applied. To leave one off, turn it off before you save.

**A past day**

Your choice is ignored. Every Personal, Shared, and Group Memory that was on at that time is attached.

**Editing**

An expense that stays on a past day keeps the Memory links it already has. Moving its day onto today lets you change the Personal ones. Group and Shared ones are taken from what is on now.

- A **Group** Memory is stored with the shared expense. The group sees it.
- A **Personal** Memory is stored on your view. Other people do not see that link.
- A **Shared** Memory is stored for you and for each person it is shared with.

The start and end you typed are not what keeps or drops the link. Turning a Memory off or completing it leaves links already saved. Deleting the Memory removes them.

If you create a Memory with a start in the past, spending already saved in that stretch is linked later. That pass only adds links.

An expense can also have a Place and a receipt. Those are separate from the Memory link. Steps: [Attach memory to an expense](/en/memories/guides/howto-attach-memory-to-expense).
