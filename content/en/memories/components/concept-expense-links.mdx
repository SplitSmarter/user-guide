# Expense links

A Memory becomes useful when an **expense** points at it. When you add an expense and choose a group, Split Smart selects the Memories that are [active](/en/memories/components/concept-current-context) for that group. Turn any of them off, or add another Memory that is not active, before you save. Saving keeps only what you left selected.

- A **Group** Memory is stored with the shared expense. The group sees it.
- A **Personal** or **Shared** Memory is stored on your view of that expense. Other people do not see that link.

The expense date must sit inside the Memory’s [date window](/en/memories/components/concept-date-window). If it does not, leave that Memory off or change the date. The expense will not save while a Memory outside its dates is still selected.

Editing an expense replaces the Memories you send. Removing a Group Memory removes it for the group. Removing your Personal or Shared Memory changes only your view.

Changing dates later can drop a link that no longer fits. Split Smart does not go back and attach a Memory to old expenses on its own.

An expense can also have a Place and a receipt. Those are separate from the Memory link. Steps: [Attach memory to an expense](/en/memories/guides/howto-attach-memory-to-expense).
