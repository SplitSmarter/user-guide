# Photos

You can attach **photos** to a Memory when you create it or later. They belong to the experience: the trip, the event, the people. They stay on the Memory after you complete it.

These photos are not expense receipts. A receipt image stays on the expense. The Memory icon is also separate: it is only the small mark in lists. See [Identity and icon](/en/memories/components/concept-identity).

Add photos from the Memory itself. Removing a photo from the Memory does not delete the expenses linked to that Memory.
