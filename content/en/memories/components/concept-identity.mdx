# Identity and icon

Every Memory has a **title** so you can tell trips and events apart. A short **description** is optional and helps other people in a Group or Shared Memory understand what it covers.

An **icon** is optional. It is a small image for the Memory in lists. It is not the same as the photos you attach to the experience. Those live on the Memory as a gallery. See [Photos](/en/memories/components/concept-photos).

Choose a title that still makes sense after the dates change, such as a destination or event name rather than only “this weekend.”
