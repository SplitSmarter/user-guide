# Active memory

An **active** Memory is selected for you on the next expense. You can turn it off before you save. Split Smart keeps only the Memories you leave selected. You can save an expense with none.

When you choose a group, Split Smart can offer:

- **The group's active Memory.** One Group Memory for the whole group. Creating a Group Memory for a group turns it on and replaces the previous one. Anyone adding an expense in that group sees it selected. The link sits on the shared expense, so the group sees it.
- **Your active Personal Memory for that group**, if you turned one on. It is selected only on expenses you add. The link stays on your view. Other members do not see it, and they do not get it on expenses they add.

A **Shared** Memory does not belong to a group. Turning it on does not select it for the group. Choose it yourself on the expense. The link stays on your view. People you invited can select that same Memory on their own expenses.

Turning a different Memory on does not change expenses you already saved. Those keep the Memories they were saved with until someone edits them.

You can turn an active Memory off without finishing it. Completing, archiving, or deleting it also stops offering it on new expenses. See [Activate or switch memory](/en/memories/guides/howto-activate-or-switch-memory).
