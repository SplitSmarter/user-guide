# Active memory

A Memory is **on** from the moment you turn it on until you turn it off. Creating it turns it on. Expenses at a time when it was on can belong to it. Expenses from before that, or after you turned it off, do not.

What is on for you:

- **One Group Memory** for a group. Creating a Group Memory for that group turns it on and turns the previous one off. Anyone adding an expense in the group gets it while it is on. The link sits on the shared expense.
- **Your Personal Memories.** Several can be on at once. They are not stored on a group membership. On a bill dated today, you choose which of those should stay. You can leave all of them off.
- **Shared Memories** you own or that were shared with you. They are not Personal Memories. While one is on, it is applied for you and for the people it was shared with.

To leave a Group or Shared Memory off a bill dated today, turn that Memory off before you save. You do not clear it on the expense itself.

A list for a span of days shows the Memories that were on during those days in your timezone. If you have no timezone, those days are UTC days. Filtering that list by groups shows only those groups’ Memories.

Turning a different Memory on does not rewrite expenses you already saved. Turning one off does not finish it and does not remove links already saved. Completing or archiving deactivates it, so it is no longer offered on new expenses. Deleting it removes its links. See [Activate or switch memory](/en/memories/guides/howto-activate-or-switch-memory).
