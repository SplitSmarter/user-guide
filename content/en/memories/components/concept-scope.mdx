# Scope

**Scope** decides who a Memory is for and who sees it on an expense. It does not change the photos, and it is not stored as a membership setting.

| Scope | Who it is for |
|-------|----------------|
| **Personal** | Only you. Several can be on at once. They apply to your expenses whether or not the bill is in a group. On a bill dated today, you choose which of the ones that are on should stay. |
| **Group** | The group you attach it to. One Group Memory is on for that group. It is applied to expenses in the group while it is on. The link is on the shared expense. |
| **Shared** | You plus the people you invite. It is not a Personal Memory, and it is not tied to a group. While it is on, it is applied for you and for the people you invited. |

Group Memories need a group. Shared Memories use the people you invite and cannot be tied to one group. Personal Memories stay yours.

Scope is separate from whether a Memory is [on](/en/memories/components/concept-current-context). A Group Memory can be the one the group offers, and your Personal Memories can be on at the same time. On a bill dated today, Group and Shared Memories that are on are applied. Turn one off before you save if that bill should not use it.
