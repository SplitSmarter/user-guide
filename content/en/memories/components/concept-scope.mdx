# Scope

**Scope** decides who a Memory is for and who sees it on an expense. It does not change the date window or the photos.

| Scope | Who it is for |
|-------|----------------|
| **Personal** | Only you. If you turn it on for a group, it is selected on expenses you add in that group. The link stays on your view. |
| **Group** | The whole group you attach it to. The one that is active is selected for everyone adding an expense in that group. The link is on the shared expense. |
| **Shared** | You plus the people you invite. It does not belong to a group, and it is not selected for you automatically. You attach it on the expense. The link stays on your view. |

Group Memories need a group. Shared Memories use the people you invite and cannot be tied to one group. Personal Memories stay yours.

Scope is separate from whether a Memory is [active](/en/memories/components/concept-current-context). A Group Memory can be the one the group offers, and you can also turn on a Personal Memory for that same group. Both can show up selected on an expense you add. Turn either off before you save.
