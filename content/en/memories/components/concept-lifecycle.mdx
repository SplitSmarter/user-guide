# Lifecycle

| Status | Meaning |
|--------|---------|
| **Active** | You can use the Memory, turn it on so new expenses offer it, and attach expenses that fit the date window. |
| **Archived** | The experience is finished. Completing a Memory usually archives it, sets or confirms the end date, and stops offering it on new expenses. |
| **Deleted** | The Memory is removed from normal use. It is no longer offered on new expenses. |

Most Memories are ones you create. Split Smart may rarely add a system Memory; you can ignore those unless the app shows one.

Completing does not delete expenses. It can drop Memory links whose expense dates fall outside the final window. See [Complete a memory](/en/memories/guides/howto-complete-a-memory).
