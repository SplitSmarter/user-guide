# Lifecycle

| Status | Meaning |
|--------|---------|
| **Active** | The Memory can be turned on. While it is on, new expenses can use it. |
| **Deactivated** | You turned it off, completed it, or archived it. It is no longer offered on new expenses. Links already saved stay. |
| **Deleted** | The Memory is removed from normal use. Its links on expenses are removed too. |

Most Memories are ones you create. Split Smarter may rarely add a system Memory; you can ignore those unless the app shows one.

Completing does not delete expenses, and it does not drop links because a date left the start and end. See [Complete a memory](/en/memories/guides/howto-complete-a-memory).
