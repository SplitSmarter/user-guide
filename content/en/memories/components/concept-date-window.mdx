# Date window

Every Memory has a **start**. An **end** is optional. Together they describe the experience. They are not the rule for which expenses belong. An expense belongs while the Memory was turned on. See [Active memory](/en/memories/components/concept-current-context).

The start may be in the past, when the trip or event began. It cannot be in the future. Creating the Memory turns it on from that start. If the start is in the past, spending already saved in that stretch is linked later. That pass only adds links. It does not remove ones already stored.

An end, when you set one, must be today or a later day in your timezone, and it must be after the start. If you have no timezone, today is a UTC day. Today is that timezone’s calendar day, not the date written in front of a stored time.

You can still [complete](/en/memories/guides/howto-complete-a-memory) a Memory early. Completing turns it off. Links already saved stay. See [Lifecycle](/en/memories/components/concept-lifecycle) and [Expense links](/en/memories/components/concept-expense-links).
