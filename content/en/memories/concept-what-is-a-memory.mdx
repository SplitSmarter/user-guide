# What is a Memory

A **Memory** collects spending and photos for one experience over a date range. You use the same Memory from a group, from an expense, and later from a budget. It is not tied to a single screen.

“Trip memory” is only a common example. Any Memory has the same parts.

## Where a Memory applies

- **Groups** — when a Group Memory is active, it is selected on the next expense in that group. You can also turn on a Personal Memory so it is selected on expenses you add there.
- **Expenses** — the active Memories are selected for you. Turn any off before you save. The expense date must fall inside the window.
- **Budgets** — the same Memory can limit or label a budget later; that guide is not written yet.
- **Photos** — images live on the Memory itself, separate from receipts on an expense.

A **Place** is a saved location. An expense can have both. They stay independent.
