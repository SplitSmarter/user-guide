# What is a Memory

A **Memory** collects spending and photos for one experience. You use the same Memory from a group, from an expense, and from a budget. It is not tied to a single screen.

“Trip memory” is only a common example. Any Memory has the same parts.

An expense belongs to a Memory when that Memory was turned on at the expense’s time. The start and end you type mark the experience. They do not, by themselves, decide which bills belong.

## Where a Memory applies

- **Groups** — one Group Memory can be on for the group. It is applied to expenses in that group while it is on.
- **Expenses** — Personal Memories that are on can be chosen on a bill dated today. Group and Shared Memories that are on are applied. Turn a Group or Shared Memory off before you save if that bill should not use it.
- **A span of days** — a list for those days shows the Memories that were on then, in your timezone. Filtering by groups shows only those groups’ Memories.
- **Budgets** — pick the Memory under **What counts** when you [create a budget](/en/budgets/howto-create-a-budget). Only spending linked to it counts toward that cap.
- **Photos** — images live on the Memory itself, separate from receipts on an expense.

A **Place** is a saved location. An expense can have both. They stay independent.

## Parts of a Memory

| Part | What it does |
|------|----------------|
| [Identity and icon](/en/memories/components/concept-identity) | Title, description, optional icon |
| [Date window](/en/memories/components/concept-date-window) | Start and end of the experience. Start may be in the past. |
| [Scope](/en/memories/components/concept-scope) | Personal, Group, or Shared |
| [Active memory](/en/memories/components/concept-current-context) | When the Memory is turned on, and so which expenses it covers |
| [Photos](/en/memories/components/concept-photos) | Pictures of the experience |
| [Expense links](/en/memories/components/concept-expense-links) | Spend attached while the Memory was on |
| [Lifecycle](/en/memories/components/concept-lifecycle) | Active, deactivated, or deleted |
