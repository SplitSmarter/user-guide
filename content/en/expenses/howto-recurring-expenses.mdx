# Set up recurring expenses

A one-time expense uses a single date. A recurring expense repeats on a rule you set before you save.

## Prerequisites

- You are signed in
- You are creating an expense

## Steps

1. On the expense form, tap the date.
2. Choose **Recurring Rule** instead of **Single Date**.
3. Choose how often it repeats: every few days, chosen weekdays, a day each month, or a yearly date.
4. Set **Paid by** and **Split Between** as you would for a single expense. See [Split an expense](/en/expenses/howto-split-an-expense).
5. Save.

## What good looks like

Open the expense. It shows **Recurring**. **Schedule** shows whether that repeat is **Active** or **Paused**, the date it runs from, and the next date.
