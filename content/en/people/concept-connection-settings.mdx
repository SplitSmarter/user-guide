# What a connection allows

**Friends** means they have a relation that names you. The relationship label you put on them does not by itself count.

## Groups

When you add them to a group:

- If they allow everyone, you add them.
- If they allow only friends, and they have connected with you, you add them.
- If they still accept invitations, and you cannot add them directly, they get an invite.
- If they allow nobody, you cannot add them.

## Memories and budgets

When you add them to a Memory or a budget you share:

- If they allow everyone, you add them directly.
- If they allow only friends, you add them directly only when they have connected with you. Otherwise they get an invite.
- If they allow invites only, they get an invite.
- If they allow nobody, you cannot add them.

These rules are about adding someone to a group, a Memory, or a budget. They are not about payments.
