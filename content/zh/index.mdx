# Split Smarter 帮助

Split Smarter 用来和别人一起花钱。

**Smart Ledger** 记录一笔费用：谁付了钱，谁分摊费用。这两件事不同。付了钱的人并不自动是唯一欠钱的人。

**Debt Sync** 把这变成谁欠谁。只记录钱已经移动，并不会自己抵上账单。在费用上结清那笔付款，欠下的金额才会被抵上。

## 从这里开始

用一顿晚餐，从新账户走到第一笔费用和记下的付款：

1. [创建账户](/zh/getting-started/tut-create-account)
2. [创建小组并邀请他人](/zh/getting-started/tut-create-group-and-invite)
3. [记下第一笔费用](/zh/getting-started/tut-log-first-expense)
4. [结清余额](/zh/getting-started/tut-settle-balances)

预算、Memories 和地点可以以后再说。要看清谁欠谁，不需要它们。
