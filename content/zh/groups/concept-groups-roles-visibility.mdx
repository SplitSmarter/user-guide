# 小组、角色和可见性

创建小组的人是 **admin**。后来加入的人从 **members** 开始。**coordinator** 拥有和 admin 一样的额外操作。

你在 **Members** 上看到一个人的角色。

## 谁能做什么

**Admin** 和 **coordinator** 可以：

- 编辑小组
- 邀请并添加人
- 记录费用
- 批准成员
- 管理结算和预算

**member** 不编辑小组，也不管理结算或预算。成员可以记录费用、邀请、添加人，以及批准成员，但只在小组把这些操作留开的时候。

## 公开和私密

**public** 小组在仍接受成员时可以被找到。**private** 小组只给成员和被邀请的人。新小组从 public 开始。

别人如何加入见 [邀请成员](/zh/groups/howto-invite-members)。他们是立刻加入还是收到邀请，取决于 [连接允许什么](/zh/people/concept-connection-settings) 里的设置。
