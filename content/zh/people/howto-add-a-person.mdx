# 添加一个人

你从首页钱包添加一个人。保存需要这个人和一种关系。

## 开始之前

- 一个你已登录的账户

## 步骤

1. 在首页钱包打开创建面板。
2. 选择 **Person**。屏幕问 **Who is this relationship with?**
3. 按姓名、电话号码或邮箱搜索。
4. 如果他们已经在 Split Smarter 上，选择他们的账户。如果还没有，选择 **Add “…” as custom contact**。
5. 选择一种 **Relationship**，例如 Friend 或 Family。如果没有合适的，可以在那个屏幕上创建新的种类。
6. 保存。在人和关系都选好之前，保存不可用。

自定义联系人仍然是你的联系人，带着那个关联。他们加入之后会发生什么，见 [自定义联系人](/zh/people/howto-custom-contacts)。
