# 附加地点或收据

一笔花费上有三件不同的事。

- **地点**是费用上的 **Location**：你当前的位置、一个已保存的地点，或没有。见 [在费用上](/zh/places/concept-place-on-expense)。
- **收据**是账单的照片。它不是地点。
- **商户分店**是你在转账上选择商户之后挑选的位置。见 [在转账上](/zh/places/concept-place-on-transfer)。

把以后还会用的地点保存在 [保存一个地点](/zh/places/howto-save-a-place)。Memory 是分开的：[把 Memory 加到费用上](/zh/memories/guides/howto-attach-memory-to-expense)。
