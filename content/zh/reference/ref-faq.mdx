# 常见问题

## 记录转账会抵上账单吗？

不会。保存转账只记录钱已经移动。账单保持未结。

## 谁付了钱，谁分摊费用？

**Paid by** 是把钱付出去的人。**Split Between** 是分摊这笔费用的人。他们可以是同一批人，也可以不是。见 [分摊一笔费用](/zh/expenses/howto-split-an-expense)。

## 明细是什么？

明细是账单上的一件东西，例如一道菜。你可以说明谁为这一行付了钱、谁分摊这一行。见 [添加明细](/zh/expenses/howto-add-line-items)。

## Category 是什么？

Category 是账单的标签。你可以在自己的副本上保留另一个。见 [Category](/zh/expenses/concept-category)。

## 照片或备注会保存这笔费用吗？

不会。账单照片或写下的备注只填一份草稿。在你确认之前，什么都不会保存。见 [从收据或备注添加费用](/zh/expenses/howto-add-from-receipt-or-note)。

## 费用保存之后还能改吗？

可以。打开它，改你需要改的地方。保存后会重新计算每个人还欠多少。见 [修改已保存的费用](/zh/expenses/howto-change-a-saved-expense)。

## 重复费用是什么？

规则就是重复费用。已排期列表是这条规则已经生成的日期，以及之后的每一个日期。见 [设置重复费用](/zh/expenses/howto-recurring-expenses) 和 [查看已排期的费用](/zh/expenses/howto-scheduled-expenses)。

## Add transfer 是人们用来结清的吗？

不是。费用上的 **Add transfer** 是付给商家的。它和账单一起保存。它不是人们结清欠款的方式。见 [在费用上](/zh/settlements/concept-add-transfer-on-expense)。

## 预算可以从过去开始吗？

可以。开始可以是任何一天，包括已经过去的一天。已经落在那个开始日期里的花费会计入上限。结束可以保持开放，或者必须是今天或更晚。结束不能早于开始。见 [创建预算](/zh/budgets/howto-create-a-budget)。

## 硬上限做什么？

**Soft** 在大约 80% 和达到上限时提醒。费用仍会保存。**Hard** 可以拒绝一笔会超过上限的新费用。它不会阻止转账。见 [上限做什么](/zh/budgets/concept-budget-rules-and-caps)。

## Memory 是什么？

Memory 是一次经历，例如一次旅行，在它开启期间附上花费和照片。你也可以在预算的 **What counts** 里选择它，让只有那些花费计入。见 [什么是 Memory](/zh/memories/concept-what-is-a-memory)。

## Hidden 是什么意思？

**Hidden** 表示其他人不能发现你。他们搜索要添加的人时，你不会出现。见 [谁能找到你](/zh/account/howto-manage-profile-visibility)。
