# 入门

用一顿晚餐看看 Split Smarter 是做什么的。Alice 付了 ₹1000。她的份额是 ₹400。Bob 的份额是 ₹600。费用保存之后，**Bob 欠 Alice ₹600**。记下 Bob 的付款，只有在费用上结清之后才会抵上这笔欠款。

## 路径

1. [创建账户](/zh/getting-started/tut-create-account)，这样你才能登录。没有访客入口。
2. 为这顿晚餐 [创建小组并邀请他人](/zh/getting-started/tut-create-group-and-invite)。
3. [记下第一笔费用](/zh/getting-started/tut-log-first-expense)，Alice 是付款人，两个人的份额都已设置。
4. [结清余额](/zh/getting-started/tut-settle-balances)，记下 Bob 付给 Alice 的 ₹600。

做完之后，那笔转账已保存，晚餐费用上的 **Settlement Path** 把这 ₹600 显示为已结清。
