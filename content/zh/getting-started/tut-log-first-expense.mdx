# 记下第一笔费用

在 Smart Ledger 里记下这顿晚餐。Alice 付了 ₹1000。她的份额是 ₹400。Bob 的份额是 ₹600。保存之后，**Bob 欠 Alice ₹600**。

谁付了钱和谁分摊费用是两件事。见 [付款人与分摊人](/zh/expenses/concept-paid-by-vs-sharers)。

## 开始之前

- [创建小组并邀请他人](/zh/getting-started/tut-create-group-and-invite) 里的晚餐小组
- 你以账单上的一个人登录

## 步骤

1. 在首页钱包打开创建面板，选择 **Expense**。
2. 选择晚餐小组。
3. 金额设为 ₹1000，日期设为今天。
4. 在 **Paid by** 下把 Alice 设为付了 ₹1000 的人。
5. 在 **Split Between** 下把 Alice 的份额设为 ₹400，Bob 的份额设为 ₹600。
6. 让 Place 保持关闭。日期为今天的账单上，如果这顿晚餐不属于某条 Personal Memory，就让它们保持关闭。已经开启的 Group 或 Shared Memory 会被加上，除非你在保存前先关闭它。
7. 保存。

不要使用这个屏幕上的 **Add transfer** 开关。那个开关记录付给账单上商家的钱。它不会结清 Bob 欠 Alice 的金额。

## 完成后

打开费用。Bob 欠 Alice ₹600。**Settlement Path** 仍把这笔金额显示为待结。
