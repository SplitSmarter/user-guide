# 完成 Memory

旅行或活动结束时，**完成**这条 Memory，这样新费用就不再使用它。完成会使它 deactivated。它不会被归档，也不会移除已经保存的关联。

## 前提

- 一个可用的 Split Smarter 账户
- 一条你可以编辑的 Memory（通常是你创建的，或小组可以编辑的）

## 完成会做什么

1. 设置或确认**结束**日期。该日期必须是你的时区里的今天或更晚，并且晚于开始。
2. 使 Memory **deactivated**。关闭或归档也会如此。它不再出现在新费用上。
3. 留下已经保存的关联。不会因为日期离开开始和结束而丢掉它们，也不会添加新的。

费用仍留在 Smart Ledger。只有删除这条 Memory 才会移除它的关联。

## 步骤

1. 打开要结束的 Memory。
2. 选择 **Complete**（或应用里的同等操作）。
3. 如果有提示，确认结束日期。它不能是你的时区里今天之前的一天。
4. 保存或确认完成。
5. 检查：
   - Memory 显示为 deactivated。
   - 新费用不再使用它。
   - 已经关联它的费用仍然显示它。

## 提示

- 只停用也会让新费用不再使用它，而不设置一个结束日。经历结束时再完成。
- 下一次经历，创建或开启另一条 Memory。
