# Memories

**Memory** 是一次经历，例如旅行、活动或项目周，你可以把它用在发生花费的地方。这包括 Smart Ledger 里的费用，以及预算的 **What counts**。Memory 不是 Place，本身也不是一个小组。

花费在 Memory 开启期间才属于它，并不是因为费用日期落在你填写的开始和结束之间。
