# 什么是 Memory

**Memory** 收集一次经历的花费和照片。同一条 Memory 可以从小组、费用和预算里使用。它不绑在某一个画面上。

“旅行 Memory”只是常见例子。任何 Memory 的组成部分都一样。

费用在那条 Memory 当时开启时才属于它。你填写的开始和结束标出这次经历。它们本身不决定哪些账单属于它。

## Memory 用在哪里

- **小组** — 一个小组同时可以有一条开启的 Group Memory。它开启期间会加到该小组的费用上。
- **费用** — 日期为今天的账单上，你可以选择哪些已开启的 Personal Memories 保留。已开启的 Group 和 Shared Memories 会被加上。如果这张账单不该使用某条 Group 或 Shared Memory，请在保存前先关闭它。
- **一段日期** — 这段日期的列表会显示在你的时区里当时开启的 Memories。按小组筛选时，只显示这些小组的 Memories。
- **预算** — 创建预算时，在 **What counts** 里选择这条 Memory。只有和它关联的花费会计入该上限。见 [创建预算](/zh/budgets/howto-create-a-budget)。
- **照片** — 图片在 Memory 上，和费用上的收据分开。

**Place** 是保存的地点。一张费用可以同时有两者。它们保持独立。
