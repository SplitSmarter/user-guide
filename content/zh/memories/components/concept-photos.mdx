# 照片

创建 Memory 时或之后，你可以给它加**照片**。它们属于这次经历：旅行、活动、人。完成 Memory 之后，照片仍留在上面。

这些照片不是费用收据。收据图片留在费用上。Memory 图标也是分开的：它只是列表里的小标记。参见 [名称和图标](/zh/memories/components/concept-identity)。

从 Memory 本身添加照片。从 Memory 移除照片不会删除已关联的费用。
