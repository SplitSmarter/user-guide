# 名称和图标

每条 Memory 都有**标题**，方便区分旅行和活动。简短**说明**是可选的，帮助 Group 或 Shared Memory 里的其他人理解它涵盖什么。

**图标**是可选的。它是列表里 Memory 的小图。它不是你附加到经历上的照片。那些照片在 Memory 的相册里。参见 [照片](/zh/memories/components/concept-photos)。

选择一个日期改变后仍然清楚的标题，例如目的地或活动名称，而不只是“这个周末”。
