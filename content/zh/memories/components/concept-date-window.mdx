# 日期范围

每条 Memory 都有**开始**。**结束**是可选的。它们一起描述这次经历。它们不是哪些费用属于它的规则。费用在 Memory 开启期间才属于它。参见 [开启中的 Memory](/zh/memories/components/concept-current-context)。

开始可以是过去，也就是旅行或活动开始的那天。不能是将来。创建 Memory 会从那个开始把它开启。如果开始在过去，那段时间里已经保存的花费会在之后被关联。这一步只添加关联，不会移除已经保存的关联。

结束如果填写，必须是你的时区里的今天或更晚的一天，并且晚于开始。如果没有时区，今天是 UTC 的一天。今天是该时区的日历日，不是存储时间前面写下的日期。

你仍可以提前 [完成](/zh/memories/guides/howto-complete-a-memory) 一条 Memory。完成会把它关闭。已经保存的关联会留下。参见 [状态](/zh/memories/components/concept-lifecycle) 和 [费用关联](/zh/memories/components/concept-expense-links)。
