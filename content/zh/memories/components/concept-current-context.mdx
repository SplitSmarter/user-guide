# Active memory

An active Memory is selected when you add an expense in that group. You can turn it off before you save. A Group Memory is selected for the group. A Personal Memory you turned on for that group is selected only on expenses you add, and stays on your view. A Shared Memory is not selected for you; you choose it on the expense. See the English page for the full explanation.
