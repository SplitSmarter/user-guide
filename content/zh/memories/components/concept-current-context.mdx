# 开启中的 Memory

Memory 从你开启它的那一刻起就是**开启**的，直到你关闭它。创建它就会开启它。它开启时的费用可以属于它。在那之前，或你关闭之后的费用，则不属于它。

对你而言，开启的是：

- 小组的**一条 Group Memory**。为该小组创建 Group Memory 会开启它，并关闭之前那条。它开启期间，在该小组添加费用的人都会得到它。关联在共享费用上。
- **你的 Personal Memories。** 可以同时开启多条。它们不存在小组成员资格上。日期为今天的账单上，你选择哪些保留。也可以全部不选。
- 你拥有的，或分享给你的 **Shared Memories**。它们不是 Personal Memories。一条开启时，会为你和被分享的人加上。

要让日期为今天的账单不使用某条 Group 或 Shared Memory，请在保存前关闭那条 Memory。你不能只在这张费用上把它清掉。

一段日期的列表会显示在你的时区里那些天开启过的 Memories。如果没有时区，那些天是 UTC 日。按小组筛选该列表时，只显示这些小组的 Memories。

开启另一条 Memory 不会改写已经保存的费用。关闭一条并不会结束它，也不会移除已经保存的关联。完成或归档会使它 deactivated，因此不再出现在新费用上。删除它会移除它的关联。参见 [开启或切换 Memory](/zh/memories/guides/howto-activate-or-switch-memory)。
