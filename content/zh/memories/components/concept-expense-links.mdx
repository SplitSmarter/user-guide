# Expense links

When you add an expense in a group, active Memories are selected. You can turn them off before you save. A Group Memory link is on the shared expense. A Personal or Shared Memory link stays on your view. The expense will not save while a selected Memory's dates do not cover it. See the English page for the full explanation.
