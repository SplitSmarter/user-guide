# 状态

| 状态 | 含义 |
|--------|---------|
| **Active** | Memory 可以被开启。它开启期间，新费用可以使用它。 |
| **Deactivated** | 你关闭了它、完成了它，或归档了它。它不再出现在新费用上。已经保存的关联会留下。 |
| **Deleted** | Memory 从日常使用中移除。费用上的关联也会被移除。 |

大多数 Memory 是你创建的。Split Smarter 偶尔可能添加一条系统 Memory；除非应用显示它，否则可以忽略。

完成不会删除费用，也不会因为日期离开开始和结束而丢掉关联。参见 [完成 Memory](/zh/memories/guides/howto-complete-a-memory)。
